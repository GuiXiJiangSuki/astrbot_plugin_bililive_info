# 哔哩哔哩查直播 · 直播信息

> ⚠️ **测试版（v0.0.1）**
>
> 本插件仍在测试阶段，功能可能随时调整，遇到问题欢迎反馈。
> 依赖 [汐汐工具箱](https://github.com/GuiXiJiangSuki/xixi-toolbox-release) 提供数据，需先部署汐汐工具箱。

AstrBot 插件：查询 B 站直播间数据，渲染成深色看板图片；支持把礼物 / 醒目留言 / 盲盒 / 上舰 实时转发到群。

## 前置要求

需要先部署 **汐汐工具箱**（单端口一体化直播助手），它负责：

- 连接 B 站直播间（弹幕 / 礼物 / 舰长等）
- 提供历史数据查询接口
- 提供实时事件推送通道

## 配置

安装后在 AstrBot 面板「插件配置」填：

| 配置项 | 说明 | 示例 |
|---|---|---|
| 汐汐工具箱地址 | 汐汐主界面地址（不带结尾斜杠）| `http://192.168.1.135:8800` |
| 历史数据查询地址 | 汐汐内置数据库查询接口 | `http://192.168.1.135:8801` |
| 看板显示主播头像 | 图片左上角是否显示头像 | 开 |
| 启用监听转发 | 是否连汐汐的转发通道 | 开 |

## 命令

### `/查直播` —— 查数据看板

```
/查直播 6154037         房间号
/查直播 Asaki大人       主播名字（自动搜索）
/查直播 194484313       主播 UID
```

支持模糊匹配：`/查直播 asaki`、`/查直播 鬼汐`

### `/订阅直播` —— 添加监听到汐汐

```
/订阅直播 Asaki大人     按名字
/订阅直播 6154037       按房间号
/订阅直播 194484313     按 UID
```

添加后汐汐会自动连接该房间，之后 `/查直播` 才有实时数据。

### `/订阅列表` —— 查看已监听的主播

### `/查成分` —— 查观众成分

```
/查成分 <B站UID或昵称>
```

## 监听转发（把直播事件推到群）

### `/添加监听转发 <房间号>`

把指定直播间的 **礼物 / 醒目留言 / 盲盒 / 上舰** 实时转发到当前群。

- 如果汐汐还没监听这个房间，会自动加进去
- 每个群可以转发多个直播间

```
/添加监听转发 6154037
```

### `/撤销监听转发 <房间号>`

停止把该直播间的事件转发到当前群（直播间仍在汐汐监听列表里）。

### `/监听转发列表`

查看当前群里都转发哪些直播间。

### `/测试转发`

往当前群发一条测试消息，确认转发链路是否通。

### 管理页面

AstrBot 面板 → 插件 → **监听转发**

可以在这个页面：

- 查看所有转发规则（群号 + 直播间 + 主播名 + 直播状态）
- 改每条监听的**礼物金额门槛**（低于这个金额的礼物不转发）
- 删除转发规则

## 转发消息格式

```
[礼物] 某某(123456)投喂了1个粉丝团灯牌(¥0.1)
[醒目留言] 某某(123456)说: 谢谢主播(¥30)
[盲盒] 某某(123456)投喂了1个幸运盲盒，开出 星光铃铛(¥5.2)，赚0.2
[上舰] 某某(123456)成为了舰长
```

多个直播间转发到同一个群时会带主播名前缀：

```
【鬼汐酱】[礼物] 某某(123456)投喂了1个...
```

## 依赖

- `aiohttp>=3.8.0` —— HTTP 请求
- `Pillow>=9.0.0` —— 看板图片渲染

## 已知限制

- 测试版，接口和行为可能变动
- 汐汐工具箱必须在运行状态，否则查询和转发都会失败
- 大航海名单需要汐汐在页面点「刷新」同步过才有完整数据
